## Input contract

Every Python, CLI and MCP mutation requires the generation from the same
screenshot as its width and height. A matching size with a different generation
is rejected before touch, key or navigation input. The verified generation stays
pinned for the operation, and the daemon continues to reject rotation during
input. Errors release the input lease.

MCP keeps six tools and lossless PNG plus structured metadata. Its instructions
require serialized actions, image inspection and a fresh screenshot before
retrying an ambiguous failure. Existing MCP connections need to reload their
tool schemas; newly started connections use the updated registration.
